# Go Pincode Service

Backend service built with:
- Go
- Gin
- GORM
- MySQL

Features:
- Pincode lookup
- Excel fallback
- Auto DB caching

## Developer & Agent Guidelines
This project utilizes a Map of Content ([[MOC.md]]) in the root directory to maintain context and track system design across sessions.
- **First Step**: Always review [[MOC.md]] on startup to understand component locations and open design issues.
- **Maintenance**: Update [[MOC.md]] when files are added, modified, or removed, and manage the "Open questions" section as tasks progress.
